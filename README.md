# Hex

Утилита на Bash для просмотра файлов в hex-формате через терминал.
Вдохновлена hex-редактором из Midnight Commander.

## Что уже умеет

- Запрашивать у пользователя имя файла
- Проверять, существует ли файл
- Выводить содержимое файла в hex через `xxd`
- Показывать адреса, hex-код и ASCII-представление
- Отлично работает с латиницей, бинарными файлами, архивами

## Ограничения

- Кириллица в ASCII-колонке отображается точками (это нормально — hex показывает байты, а не текст)
- Кириллица занимает 2 байта в UTF-8, поэтому в hex выглядит как два отдельных байта
